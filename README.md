# Kali-linux-docker-makefile

Контейнеризированный шаблон для безопасного сканирования веб-сайта на уязвимости с использованием:
- OWASP ZAP (baseline + full scan)
- Nikto
- Nmap

> ⚠️ Легальность и ответственность
> Используйте этот проект **только** с явного разрешения владельца ресурса. Автор проекта не несёт ответственности за неправомерное использование. Вы подтвердили, что вы — разработчик/владелец.

## Структура
- `Dockerfile` — билд образа на базе `owasp/zap2docker-stable`, с nikto и nmap.
- `scan.sh` — последовательный запуск ZAP, Nikto и Nmap (используется в `make scan`).
- `Makefile` — удобные цели: `make build`, `make scan`, `make zap-baseline`, `make nikto`, `make nmap`.
- `reports/` — папка для отчётов (монтируется в контейнер).

## Требования
- Docker (последняя стабильная версия)
- Свободное место для отчётов

## Быстрый старт
1. Склонировать репозиторий.
2. Сменить директорию: `cd Kali-linux-docker-makefile`
3. Собрать образ:
   ```bash
   make build
   ```

4. Запустить полный набор сканов (пример):

   ```bash
   make scan TARGET=http://your-target.example.com
   ```

   Отчёты появятся в `./reports/`.

## Примеры команд

* Только ZAP baseline:

  ```bash
  make zap-baseline TARGET=http://your-target
  ```
* Только Nikto:

  ```bash
  make nikto TARGET=http://your-target
  ```
* Nmap:

  ```bash
  make nmap TARGET=example.com
  ```

## Настройка и расширение

* Для интеграции с CI (GitHub Actions) можно запускать `docker build` + `docker run` с монтированием артефактов отчётов.
* Можно добавить `sqlmap` или другие инструменты (учтите ответственность и правила).
* Подстраивайте `nmap` опции (полный порт-скан `-p-`) и ZAP параметры по необходимости.

## Безопасность

* Не храните чувствительные данные в отчётах.
* Отключайте агрессивное сканирование на боевых сайтах без тестовой среды.
